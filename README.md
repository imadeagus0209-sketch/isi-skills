# ui-qrio Skills

Agent Skills untuk project ui-qrio — Next.js 13 enterprise admin dashboard.

## Install

```bash
npx skills add imadeagus0209/ui-qrio-skills
```

## Skills yang Tersedia

| Skill | Deskripsi |
|-------|-----------|
| `check` | Pre-commit check — TypeScript, ESLint, git diff |
| `new-crud` | Scaffold CRUD lengkap (type, validation, service, store, sidebar, table, page) |
| `new-page` | Scaffold halaman list read-only dengan filter bar + DataGrid |
| `new-service` | Scaffold service + Zustand store untuk domain baru |
| `auth-config` | Referensi arsitektur Auth — login/logout flow, token, socket init, provider tree |
| `http-config` | Referensi HTTP config — dynamic URL resolution, axios interceptors |
| `zustand-store` | Referensi global state Zustand — pola store, cara akses, store global |

## Stack

- Next.js 13 · React 18 · TypeScript
- MUI v5 · Zustand · Axios
- Socket.IO client · Yup + React Hook Form

## Kompatibel Dengan

Claude Code, Cursor, GitHub Copilot, dan semua agent yang mendukung [Agent Skills](https://agentskills.io).
